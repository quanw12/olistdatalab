# Day 18 — Docker and Linux CLI from the beginning


Learn the Linux commands, then run PostgreSQL 18 with the named volume and host5433 binding. Create .env locally without committing it. Bootstrap the container DB using your own SQL and load the base fixture with host Python.

Stop/start the container and verify base 8 observations persist. Capture version, readiness, table counts and an explanation of image/container/volume/port in reflection.md. Keep this volume for Day 19. Do not remove the volume to solve an unexplained error.
