# Data Engineering foundations — 30 daily lessons

Build a weather pipeline while learning the tools behind it. This is a foundation course; deeper Python, SQL, system design, and internship interview practice belong in the next stage.

## Start here

1. Read [setup.md](setup.md) for the environment and working folders.
2. Find your next lesson in [roadmap.md](roadmap.md).
3. Read guide.md, then lesson.md.
4. Read exercise.md and write your solution in its named exercise files.
5. Open help.md when stuck; compare with expected.md after your attempt.
6. Save explanations and evidence, get a review, and commit.

Each day is one lesson. Allow 2.5–4 hours or split a difficult lesson across sessions.

## Folder map

~~~text
de-30-days/
  README.md, roadmap.md, setup.md, resources.md, progress.md
  data/             fixed fixtures for Days 13–30
  capstone/         project you build from Day 14 onward
  day-01/ ... day-30/
    guide.md        learning order, run instructions, and commit commands
    lesson.md       concepts and syntax examples
    exercise.md     assignment and acceptance criteria
    help.md         detailed implementation hints and debugging
    expected.md     expected values or observable evidence
~~~

Exercise Python/SQL files contain problem comments, not solutions. Data fixtures and explicitly marked setup/check SQL are provided support materials.

Days 1–11 preserve your saved files in previous-work inside each day. These are historical submissions, not certified answer keys. Fresh exercise files allow another attempt. Unfinished Day 12 work remains in the stash described in the repository README.

## One connected project

Days 1–7 cover Python and extraction; 8–12 cover SQL and modeling; 13–17 build a local pipeline; 18–23 add containers, orchestration, tests, and quality; 24–27 cover warehouse basics, analysis, CI, and evaluated AI assistance; 28–30 complete the portfolio.

Read [the shared project contract](capstone/contract.md) at Day 13. It fixes names, keys, file formats, and interfaces so the lessons fit together.

Track your work in [progress.md](progress.md). Its checkboxes start unchecked: preparing lessons does not mean you have completed them. Install dependencies when each guide introduces them. Label offline and live evidence accurately.
