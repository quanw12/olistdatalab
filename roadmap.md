## Difficulty and hints

Every guide states **Learn, Apply, Integrate or Assess** — see [definitions](docs/study.md#difficulty-and-hints). Attempt before opening approach help. Record hint level used.

Foundation introduces the weather workflow. Python isolates language boundaries. Linux teaches execution around a supplied app. DE makes you own requirements, state and delivery.

## Calendar estimate

Example: **16 weeks at roughly 18–24 focused hours/week**, including SQL and repair time. Estimate only, not a hiring guarantee.

| Weeks | Main work |
|---|---|
| 1–3 | Foundation Days 1–30 (integrations may span sessions) |
| 4–7 | Python; reserve time for checkpoints and capstone |
| 8–9 | Linux execution and delivery |
| 10–14 | Core DE and integrated retail project |
| 15–16 | DE26 unfamiliar task, DE27–DE28, gate repair, handoff |

At 10–15 hours/week, extend the calendar. Practise SQL in short weekly sessions; assess with Gate B.

## Readiness and extensions

[Gates A–G](docs/assessment.md): independent results, meaningful failures, clear limits. Apply when you can demonstrate skills; materials alone are not readiness.

Then [Part 5](05-extensions/README.md): Engineering Labs → Cloud → AI Data → Streaming. Finishing all 32 is not required before applications.
