# Learning resources for the 30-day plan

Use these alongside the daily exercises. Read only the parts relevant to the current day; you do not need to finish an entire course.

| Stage | Read/watch | Days |
|---|---|---|
| Python basics | [Python Tutorial](https://docs.python.org/3/tutorial/) — control flow, functions, data structures, files, errors | 01–03 |
| Git and terminal | [Pro Git](https://git-scm.com/book/en/v2), chapters 1–2; [MIT Missing Semester](https://missing.csail.mit.edu/), shell and version control | 01, 06–07 |
| pandas | [Python for Data Analysis](https://wesmckinney.com/book/), chapters on pandas, cleaning, joining, and groupby | 04–05 |
| HTTP/APIs | [Requests Quickstart](https://requests.readthedocs.io/en/latest/user/quickstart/) | 06, 15–17 |
| SQL/PostgreSQL | [PostgreSQL Tutorial](https://www.postgresql.org/docs/current/tutorial.html); [PGExercises](https://pgexercises.com/) | 08–14 |
| pgAdmin 4 | [Server connections](https://www.pgadmin.org/docs/pgadmin4/latest/server_dialog.html); [Query Tool](https://www.pgadmin.org/docs/pgadmin4/latest/query_tool.html) — connect to local PostgreSQL, open SQL files, execute selected statements, inspect results | 08–14 |
| Docker | [Docker Get Started](https://docs.docker.com/get-started/) | 18–19 |
| Orchestration | [Prefect Quickstart](https://docs.prefect.io/v3/get-started/quickstart) | 20–21 |
| Testing | [pytest Get Started](https://docs.pytest.org/en/stable/getting-started.html) | 22–23 |
| Data warehouse | [BigQuery Sandbox](https://cloud.google.com/bigquery/docs/sandbox) | 24 |
| Broader DE foundations | [Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp) — selected Docker, warehouse, and dbt sections | After Day 24 |

## How to use external resources

1. Read for 20–40 minutes.
2. Type and run a small example yourself.
3. Apply it to the day's exercise immediately.
4. If it does not help the current exercise, pause the reading.

As a beginner, aim for enough theory to build something that runs, followed by practice.
