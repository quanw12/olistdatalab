# Tài liệu học theo lộ trình 30 ngày

Đây là tài liệu để đọc song song với các bài thực hành trong từng ngày. Mỗi ngày chỉ học đúng phần liên quan; không cố hoàn thành toàn bộ một khóa.

| Giai đoạn | Đọc/xem | Dùng cho ngày |
|---|---|---|
| Python cơ bản | [Python Tutorial](https://docs.python.org/3/tutorial/) — flow control, functions, data structures, files, errors | 01–03 |
| Git và terminal | [Pro Git](https://git-scm.com/book/en/v2) chương 1–2; [MIT Missing Semester](https://missing.csail.mit.edu/) phần shell và version control | 01, 06–07 |
| pandas | [Python for Data Analysis](https://wesmckinney.com/book/) chương pandas, cleaning, joining và groupby | 04–05 |
| HTTP/API | [Requests Quickstart](https://requests.readthedocs.io/en/latest/user/quickstart/) | 06, 15–17 |
| SQL/PostgreSQL | [PostgreSQL Tutorial](https://www.postgresql.org/docs/current/tutorial.html); [PGExercises](https://pgexercises.com/) | 08–14 |
| Docker | [Docker Get Started](https://docs.docker.com/get-started/) | 18–19 |
| Orchestration | [Prefect Quickstart](https://docs.prefect.io/v3/get-started/quickstart) | 20–21 |
| Testing | [pytest Get Started](https://docs.pytest.org/en/stable/getting-started.html) | 22–23 |
| Data warehouse | [BigQuery Sandbox](https://cloud.google.com/bigquery/docs/sandbox) | 24 |
| Nền DE tổng thể | [Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp) — xem có chọn lọc Docker, warehouse và dbt | Sau ngày 24 |

## Cách dùng tài liệu ngoài

1. Đọc 20–40 phút.
2. Tự gõ lại một ví dụ nhỏ.
3. Áp dụng ngay vào bài của ngày.
4. Nếu không dùng được vào bài, chưa cần đọc tiếp.

Đây là cách học phù hợp khi bạn mới vào DE: lý thuyết vừa đủ để viết được một thứ chạy thật.
