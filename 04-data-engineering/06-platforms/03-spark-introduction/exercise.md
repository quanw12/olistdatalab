# DE21 assignment

Write decision.md comparing PostgreSQL, DuckDB and Spark for a 1 MB file, a 2 GB local dataset and a multi-terabyte distributed workload. Discuss memory, shuffles, skew, source/output layout and operational cost without universal size cutoffs. Optional runtime: choose a released PySpark version and its matching 02-python/Java requirements, install in a separate Linux environment, aggregate the active retail rows and compare to SQL. Explain an intentional many-to-many join.

## Deliverables

decision.md and optional spark_lab.py/runtime evidence.

## Reflection

Does using PySpark make an incorrect many-to-many join correct?
