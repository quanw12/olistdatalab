# 01 — DE foundations: 30 daily lessons

[Home](../README.md) · [Overall roadmap](../roadmap.md)

This is the complete first course: **30 lessons**, each with concepts, syntax, a task, help, expected evidence and manual commit commands. Build a weather pipeline while reviewing the tools behind it.

**Continue at [Day 12: data modeling](day-12/guide.md). Days 1–11 are completed**, as confirmed by you. Their earlier files are in [submissions](submissions/README.md); your active Day 12 schema is retained.

Follow guide → lesson → assignment → help when needed → verification → reflection/commit. The [shared study guide](../docs/study.md) explains that cycle. Exercise starters contain problems; supplied data/setup/check files support the exercise.

Days 01–07 build a snapshot; 08–14 add SQL/modeling/loading; 15–21 make repeated runs reliable; 22–27 add tests, quality, reporting, CI and verified AI use; 28–30 finish the portfolio. Docker begins at Day 18, after native PostgreSQL practice.

Budget roughly 2.5–4 hours per lesson and split difficult integrations into sessions. Complete the weather project and demonstrate rerun/failure recovery before continuing to [Python](../02-python/README.md). The later courses deepen skills introduced here; they do not reset your completed days.
