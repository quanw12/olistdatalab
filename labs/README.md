# Labs

Code skeletons and tests for the exercises you implement yourself. Each folder has a file with
function signatures, docstrings and hints (no solutions) and a test file that specifies the
expected behaviour.

```powershell
pytest labs/01-python -v      # red at first; make it green
```

Instructions, context and the order in which to do the labs live in the DEcourse vault
(`DEcourse/00 - Start Here/Labs Guide.md` and each module guide), not in this folder.
Labs are not part of the default `pytest` run; add each one to CI once it passes.
