# LE12 assignment

Create runbook.md with four incidents: missing input, wrong interpreter, output path occupied by a file, and missing HTTP listener. Reproduce each in a separate lab location, capture the exact error/status and repair only its cause. After repair rerun the original successful command and compare counts. Include one table of symptom/check/cause/action/verification. Do not invent a disk-full event; explain how you would diagnose it using df/du.

## Deliverables

runbook.md plus notes.md containing evidence for the four demonstrated failures. Keep the repaired normal run's total.

## Reflection

Why must recovery end with a verified rerun rather than an error message disappearing?

Keep your final implementation separate from teaching examples. Record commands, exit codes and observations; a screenshot alone should not replace an explanation.
