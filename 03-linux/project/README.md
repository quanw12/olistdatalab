# Shared engineering project

app.py and test_app.py are supplied infrastructure, ready to run. Your learning target is engineering around a working deterministic data app.

Implement run_batch.sh at LE09; Dockerfile and .dockerignore at LE18; compose.yaml at LE20; test_extra.py and the draft workflow.yml at LE21; runbook.md at LE22. These starters contain prompts only.

The same fixture and counts are used in native Linux, containers and the HTTP viewer. Follow [the data contract](../data/README.md) and [capstone acceptance](../06-delivery/02-capstone/contract.md).

No database, paid API, cloud account or secrets are needed. The HTTP viewer is for local practice only. No root .github workflow is activated by preparing this folder.
