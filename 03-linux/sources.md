Microsoft, Docker, Git and GitHub pages were inspected. GNU manual fetches timed out in this session; those reference links are supplied for further reading, and locally executable Bash behavior was checked separately where possible. Course status codes 64/65/66/127, fixture counts and resource names are explicit lab design choices.

Author verification uses Windows Python for the supplied app/HTTP checks, Git Bash for portable Bash reference contracts/syntax, and isolated local Git repositories for collaboration mechanics. Git Bash is not Ubuntu; this does not certify native Ubuntu permission/process/network behavior.

The available Docker client could not connect to its engine. Images, mounts, Compose services and live GitHub Actions were not executed during preparation. Their exercise commands require your own runtime evidence.

The source files are prepared material; progress checkboxes are not automatically completed. Every runtime claim must identify the environment actually used.
