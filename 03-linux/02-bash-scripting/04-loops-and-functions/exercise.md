# LE08 assignment

Implement exercise.sh: sum 0–100 arguments. Each must contain ASCII digits only, length 1–7, decimal value <=1000000. Leading zeros allowed. Valid input prints only the sum/newline, status 0; no arguments -> 0. Invalid value/count -> stderr diagnosis, empty stdout, exit 65. Validate before printing; never interpret user expressions.

## Deliverables

exercise.sh and notes.md with valid/invalid boundary cases.

## Reflection

Why validate text before Bash arithmetic?

Keep your final implementation separate from teaching examples. Record commands, exit codes and observations; a screenshot alone should not replace an explanation.
